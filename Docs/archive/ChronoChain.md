# Chrono Chain — Liquid Time

この文書は旧チェーン版の記録です。通常プレイは [Liquid Assault](LiquidAssault.md) に置き換わっています。

## 起動

Development / x64 をビルドし、セレクトの先頭にある **Chrono Chain - Liquid Time** を選択する。
専用の `Resources/Scenes/chrono.json` から起動する。缶の装備画面は通らない。
Stage 1、Stage 2、Test Scene は従来のルールで選択できる。

## 操作

| 入力 | 動作 |
|---|---|
| WASD / マウス | 移動 / カメラ |
| Space | ジャンプ。短い入力先行受付・崖際の猶予あり |
| Shift | 液状回避。接近中にもキャンセル可能 |
| 左クリック | 通常は近接攻撃。オートチェーン中は候補へ腕を射出 |
| 右クリック長押し＋左クリック | 手動照準で腕を射出。命中後に接近。空振りでは移動しない |
| ホイール押し込み | オートチェーンの ON / OFF |
| F2 | 通常コース／平坦な闘技場テストを切り替えて再開始 |
| F3 | 通常コース／蛇→鳥の巨大生物テストを切り替えて再開始 |
| Esc | ポーズ |
| リザルトで R / Enter | リトライ |
| リザルトで Tab | ステージセレクト |

右クリックはオートチェーンより優先される。解除後は元の ON / OFF 状態に戻る。
長押し中は敵・ボス・弾幕を約20%の速度にし、プレイヤーと照準操作は通常速度を維持する。
解除時は滑らかに通常速度へ戻る。コンボのスローが残っている場合はそちらを維持する。
右肩越しのカメラで本体を画面左へ寄せ、チェーン中は距離と画角を広げる。
上向き照準で地面にカメラが接触した場合も、本体と腕の根元が見えるよう画角を調整する。
位置追従は指数補間でわずかに遅らせる。遅れを最大2.2×体サイズに制限し、高速接近中の本体への食い込みを防ぐ。
戦闘中の構図は移動対象と分離し、自機とボスを基準にする。通常距離を取り、上下追従を緩め、少し見下ろす角度へ補正する。
マウス操作後1.5秒と手動照準中は向きの自動補正を停止する。ボスが画面外なら方向と攻撃予告を表示する。
視界を遮る地形・木にはディザ透過を適用する（衝突と影は維持）。近すぎる自機の流体も透過を強める。
攻撃はクリックごとに発動し、動作中の次の入力を最大0.3秒保持する。クリックを離すと未実行の予約を取り消す。
実行中の移動はクリック解除だけでは止めず、Shiftで中断する。回避は攻撃予約より優先し、停止中の入力も方向ごと保持する。
回避の再使用待ち・形状崩壊中はHUDに表示する。予約した対象が消失・遮蔽された場合、別の敵へ勝手に切り替えない。
対象選択と接近開始は同じ自機サイズの通過判定を使う。通れない候補は黄色い×、通れる候補は水色の枠で区別する。
接地中は高さ0.56以下の段差を、上方と目的地までの両方の空間が空いている場合だけ補助する。
水色の結晶・破壊可能弾・小型敵・露出中の黄色い弱点へ移動できる。
赤い弾は回避対象。地形の裏の敵を捕捉せず、接近も地形を貫通しない。

## 1コースの流れ

### 巨大生物テスト（F3）

添付された参考画像の「節のある蛇・鱗の分解再構成・大きな翼」を、独自の簡易メッシュで実装した試作。
26節の胴体と鱗、左右の関節と3層108枚の羽、頭部を合わせた224部品を数式で毎フレーム配置する。
同じ部品が地上の蛇から空中の鳥へ移動し、変形中は頭部・胴体を含む全224部品が大きく散開し、層ごとに逆方向へ回転する幾何学配列を作って再集合する。首と尾はうねり、翼は肩・肘・手首・翼端の位相差を付けて羽ばたく。風切羽・雨覆・前縁の羽を立体的に重ねる。
ボスの実寸は初版の6.5倍（前版からさらに2.6倍）。プレイヤーの大きさは変更せず、頭部も構図計算に含める。
変形はボスの時間に従うため、スローとヒットストップでも部品が別々に進まない。

1. 地上で3秒うねり、8秒かけて全パーツを分離し、7層の菱形立体配列を経て翼を広げて浮上する。
2. 1.2秒の予告後、攻撃は1種類の「羽根弾」を距離に応じて5枚以上放つ。飛行中は接触するとダメージ。
3. 到着した水色の羽根は空中に留まり、左クリックで攻撃しながら乗り継げる。初期状態はオートチェーンON。
4. 同じ攻撃の羽根を3枚壊すと、胸のコアが金色になって開く。コアへグラブ攻撃すると120ダメージ。
5. 命中後は蛇へ戻る。Shiftで連鎖を中断・横回避し、着地してSTRAINを回復できる。
6. 3回のコア攻撃で撃破。届かなかった場合も開口時間終了後に戻り、羽根を補充して繰り返す。

床は700×800の平坦な専用闘技場。固定アンカー4個を残し、小敵は置かない。
移動と射線は胴体の節に簡易当たり判定を持つ。装飾の翼・鱗には個別の接触ダメージを付けない。
ボス全体の構図より自機の視認性を優先する。手動視点の優先、連鎖キャンセルと回避は通常モードと共通。
個人記録は保存せず、リトライは同じ巨大生物モードで再開する。

検証: `tests/Run-ChronoTests.ps1` が変形の有限座標・再現性・中継間隔を確認する。
ビルド後の `tests/Run-ChronoSmoke.ps1 -Creature` は自然な変形、羽根3枚の破壊、空中コア命中、直後の回避、蛇への復帰を実機で確認し、`tests/out/creature-*.png` を保存する。

### 闘技場テスト（F2）

平坦な床にボス1体、小敵3体、再利用できる固定アンカー4個を配置する。柱・外壁・低い段差も置き、遮蔽と移動を確認できる。
ボスは近接攻撃（0.85秒予告）と突進（1.1秒予告）を交互に使う。床の黄色い範囲が予告、赤が攻撃中。
突進の方向は予告開始時に固定される。攻撃後は2.6秒の隙があり、ボスへカウンターするか、着地して回復するかを選べる。
固定アンカーは到達後1.2秒で再使用でき、小敵を倒した後も移動手段が残る。着地時の表示、STRAIN警告の自機点滅、被弾原因の表示を追加。
通常コースと闘技場の記録は混ぜない。闘技場は記録保存せず、リトライすると同じ闘技場を再開始する。

### 通常コース

1. 谷の緑の角付きホッパーを、近接・手動グラブ・オートチェーンで倒す。
2. 3コンボ以上で撃破すると、敵とボスの時間が減速する。自分の入力・移動・攻撃は実時間。
3. 結晶や敵を足場に高台へ進む。敵が残っていなくても東側の幅広い階段で城砦まで歩いて登れる。
4. 「APPROACH」の予告後、水色の弾が上昇ルートを作る。弾を破壊しながら上空へ進む。
5. 同じ波の弾を3個破壊するとボスが攻撃可能になる。金色リングで示す本体の胴体へグラブ攻撃するとカウンター。オレンジの球は表示しない。
6. 3回のカウンターで撃破。タイムと最大チェーンを更新して再挑戦する。

ボス本体への通常攻撃は少量のダメージのみで、コンボは増えない。
弾は毎波補充されるため、チェーンに失敗しても再挑戦できる。
西側に3段の中継足場と緑色の復帰アンカー4個を追加。アンカーは崖の手前に出して地形に射線が埋まるのを防ぐ。
アンカーから前方の足場へ移動して着地するか、そのまま次のアンカーへ連鎖できる。
全ての移動アンカーは一度到着すると消滅し、そのプレイ中は再選択されない。途中で引き寄せが失敗した場合は残る。使用後の登り直しには階段を使える。
場外落下時は最後に十分な足場幅があった地点へ戻り、質量12を消費する（最低1）。被弾回数には加算しない。

## 調整値

初期実装の値であり、プレイテストで調整する。

| 項目 | 現在値 |
|---|---|
| 移動 / 接近 / 回避速度 | 15 / 最大115、残り7 unitsで30へ減速 / 32 units/s |
| ヒットストップ | 通常35 ms、コアへのカウンター65 ms。入力は先行受付 |
| 重力 | 上昇30、頂点付近17、下降38 units/s²。空中チェーン後の猶予あり |
| 腕の射出速度 | 110 units/s |
| 基準 / 最大質量 | 100 / 200 |
| グラブ射程 | 約12〜24 units。小さくても最低射程を確保 |
| コンボ維持 | 2秒（実時間） |
| スロー | 45%から段階的に25%まで。残り時間の上限3秒 |
| 不安定ゲージ | 大きな体・長距離移動ほど増加。着地中は毎秒32回復 |
| 崩壊 | 100到達で0.6秒硬直。質量15消費、自己崩壊だけでは死亡しない |
| ホッパー撃破 / 弾破壊 | 質量18 / 8回復 |
| ボス | HP360、弱点カウンター120、各波1回 |

質量はHPと共有し、体積・威力・射程に反映する。体の拡大は衝突空間を確認して適用する。
撃破の吸収演出、接近時の腕、ターゲット枠、スロー表示、不安定警告を追加した。

## 手触り・視認性

- 着地速度に応じて短く潰れ、元に戻る。流体の上下・外向きの力を変え、SPHと地面衝突を保つ。
- 命中時に2〜4フレーム相当の停止と最大96個の飛沫。停止中も照準と入力受付を継続する。
- 連鎖数に応じて命中SEの音程が1.0〜1.8倍へ上昇する。既存SEアセットを使用する。
- 対象枠は現在の射出先／次に繋がる候補一つだけ。全弾への線とルートの線は廃止。
- 射程外、遮蔽物、回復待ち、形状崩壊、空振り、落下復帰を照準近くに短く表示する。
- 攻略進行は上中央、質量・不安定・モード・時間速度は下中央。常時の操作説明は開始12秒で消える。
- ボスのオーブ破壊数0/3〜3/3、コアの金色リング、カウンター達成数を表示する。
- 被弾方向の赤い山形マーカーと自機の白い点滅を表示し、場外落下と区別する。
- スロー中は画面周辺の放射状ブラー、寒色化、減彩を適用。照準中央とHUDはぼかさない。
  深度被写界深度は使用していない。専用の8サンプルのポストプロセスで負荷を抑える。

## リザルト

クリア時間、最大チェーン、カウンター数、最大連続空中撃破、破壊弾数、最大質量、
被弾数、崩壊数、手動 / オート接近数、スロー継続時間、S〜Cランクを表示する。
ランクはチェーン35点・カウンター35点・時間20点・被弾と崩壊10点。
破壊数の無制限な稼ぎで評価が上がり続けないよう、得点に上限がある。
最速時間と最大チェーンは `%LOCALAPPDATA%/LiquidTime/records-v1.json` に保存する。

## 実装構成

- `Game/Chrono/ChronoRules.h`: エンジン非依存の時間・体積・判定・評価ルール。
- `Game/Chrono/ChronoComponents.h`: プレイヤー、対象、小型敵、弾、ボスの状態。
- `Game/Systems/ChronoSystem.cpp`: 専用ステージ、移動、照準、接近、戦闘、UI。
- `GameScene`: 専用モードのシステム登録、流体連携、時間の適用。
- `FluidSimCS.hlsl` / `Renderer.cpp`: 基準質量100では他シーンと同じ6600粒子・凝集力・速度追従を使用。
  通常移動で粒子を一括移動させず、加減速による揺れを残す。高速接近だけ移送を補助する。
  質量100未満では粒子スロットを減らし、100を超えると密度を下げて体積を増やす。上限6600粒子。
- `SetGPUFluidTether`: 本体の粒子の一部を湾曲・先細りに変形させて腕を伸ばす。
  本体と同じSPH計算・流体描画・衝突判定を使い、円柱メッシュや別の腕用粒子を生成しない。
  手動射出・オート接近・空振り後の収縮に連動し、下方向の腕も描画範囲に含める。
  伸長中は細い腕の形状拘束を毎サブステップと密度補正に適用し、圧力による散乱を抑える。
  物理計算後の位置へ逆伸縮を累積せず、射出開始時の体内位置へ戻す。
  腕に使う粒子の識別を固定し、質量の増減で腕全体の配置が入れ替わらないようにする。
  腕が短くなると拘束を緩め、体内の密度補正に任せて戻す。収縮中は相対速度を抑え、
  戻る粒子と本体が押し合って飛散することを防ぐ。

地形はFBX床ブロック、木、山パーツで構成する。見た目と対になるBoxColliderコンポーネントを持ち、
移動には連続判定を使用する。敵同士は重なりを解消する。
現在は専用の1コース・1種類のボス弾幕と、近接／突進を備えた闘技場試作を含む。
地形・配置の編集場所は `ChronoSystem::Build`。エディタで生成物を直接保存しても、開始時に再生成される。
新しいコンポーネントのInspector編集・任意のステージへの汎用配置は未対応。

## 検証

```powershell
powershell -ExecutionPolicy Bypass -File tests/Run-ChronoTests.ps1
powershell -ExecutionPolicy Bypass -File tests/Run-FluidTests.ps1 -Case --chrono-only
powershell -ExecutionPolicy Bypass -File tests/Run-ChronoSmoke.ps1
```

流体の専用テストは実際のHLSLをWARPで実行し、他シーンとの通常移動の一致、既存粒子の伸縮、
下方向への伸長、収縮、近傍力計算中の有限値、高速追従を検証する。
6600粒子・質量185で方向反転と短縮を繰り返す72ステップのPBF計算では、
腕の横幅と先端までの粒子分布も確認する（有限値だけでは飛散を検出できないため）。
続く180ステップでは実際の収縮速度で腕を戻し、本体全体に遠くへ飛んだ粒子が残らないことを確認する。
最後のコマンドはDevelopment実行ファイルを非表示で起動する。別のゲーム実行中には停止する。
冒頭で闘技場の生成、命中停止中の回避保持、攻撃より回避を優先すること、クリック解除で予約を破棄すること、接近中の左右回避を検証する。
近接攻撃の被弾原因、突進の移動、攻撃後の弱点露出も実際のシステムで確認し、`chrono-arena.png`を保存する。
階段の歩行、手動の空振りと命中、オート接近、スロー、弾破壊、3回のカウンター、
リザルト、STOP/PLAY再開を検証し、`tests/out/chrono-*` に画面とログを保存する。
個人のベスト記録は更新しない。ボス検証開始時は残りの雑魚を無効化して判定を分離する。
自動プレイの所要時間はプレイヤーが実際に遊ぶクリア時間の目安にはしない。
右肩越しの位置、長押し中の20%スロー、解除後の復帰も検証する。
着地の非貫通と変形、命中停止中の自機・ボス停止、スロー演出、失敗表示も通しプレイで検証する。
復帰ポイント間は実際の地形コライダーと自機の大きさで通過可能性・射程を検証し、STOP時のポストエフェクト解除も確認する。
ボスの波を待つ検証時間はGPUのフレーム数に左右されないよう実時間65秒を上限とする。
ルールテストでは30/60/144 FPSでカメラ遅延の上限と収束、接近の減速と到着、重力・着地の復元を検証する。
流体テストでは着地時に頭頂部へ下向きの力が作用し、速度が有限であることも確認する。
`chrono-shoulder-aim.png` と `chrono-liquid-side.png` は実際のゲームカメラで照準・伸長中を記録する。

既存の `Run-FluidTests.ps1` には `player crown is pushed sideways or collapses` の失敗がある。
変更前のHEADの流体シェーダーでも同じ失敗を再現した。全流体テストが成功したとは扱わない。
新モードはD3D12で実際に描画・プレイして確認するが、全ハードウェアでのFPS保証ではない。

巨大化後は距離に応じて中継羽根を補充し、開口時間40秒・羽根寿命44秒を確保する。羽根の破壊でSTRAINを12軽減し、長い上昇連鎖を維持できる。変形中も戦闘用のカメラ距離を維持する。

## 巨大ボス戦の操作・視認性調整

- 床は透過しない。カメラ衝突は静的な床・壁で解決し、動くボス部品は視界遮蔽時の透過で扱う。
- 巨大ボス戦の通常カメラ距離は21×体サイズ。変形時の強制ズームアウトを廃止し、距離変更に速度・加速度制限を付ける。巨大ボス全体を収めるためのFOV拡大も行わない。
- 緑の鱗状中継点は蛇形態から利用でき、変形に合わせて上昇する。捕捉・予約・選択中の中継点は位置を固定する。
- 羽根は飛来中が赤・縦向き、利用可能になると水色・横向きになり、展開完了音を鳴らす。展開は実時間0.45秒＋最大0.18秒の遅延。
- 空中ルートは44秒残る一本の羽根列。捕捉時にSTABLE FEATHERを表示し、使用済み・攻撃終了後の羽根を除去する。
- 手動では命中後70〜320msの次入力で接近速度が15%ずつ上がり、上限150%。通常入力は最大115%。AUTOは長押しの連鎖で150%まで加速。終点では減速を維持する。回避・被弾で解除し、1.2秒途切れると減衰する。
- 巨大ボス戦のFOVは65度を基準に加速に応じて最大75度へ広がる。SHIFTの回避は引き続き攻撃予約より優先。

## 蛇の横薙ぎ（F4で反復検証）

F3の通常巨大生物戦では蛇形態で一度横薙ぎしてから鳥へ変形する。F4は蛇戦だけを繰り返す。3回コアを攻撃すると勝利し、R/Enterで同じモードを再開できる。

- 2秒の準備後、1.2秒予告。開始時のプレイヤー位置に攻撃帯を固定し、頭を左へ引く。黄色い床枠と右向きの矢印が予告。
- 0.28秒の横薙ぎ。床表示が赤くなり、左から右へ判定が進む。横幅30、奥行10、高さ4.5未満が危険。地上では帯の外へ後退・回避し、緑の鱗では上方へ逃げられる。
- 攻撃中は一度だけ22ダメージ。被弾理由を表示し、既存の短い復帰・無敵時間で立て直せる。
- 空振り時のみ3秒コアが開く。羽根3枚の条件は不要。被弾させた場合はこの隙にコアを開かない。
- 0.8秒かけて姿勢を戻す。F4では次の予告へ、F3では変形へ進む。
- 鱗の逃げ道は予告開始時に配置して攻撃中は固定する。攻撃部位は通常の押し出し判定ではなく、予告帯と一致する専用ダメージ判定を使う。

`tests/Run-ChronoSmoke.ps1 -Snake` は、棒立ち被弾→次の攻撃で地上回避・反撃→鱗で上方回避・反撃を実入力経路で確認する。各ラウンド開始位置のみ検証用に揃え、ボスのタイマーや命中結果は改変しない。

## 攻撃と演出の拡張

- F4は横薙ぎ→直線突進→頭叩きつけを最初に順番に実行。その後は高度・距離で選び、同じ攻撃の連続を避ける。F3では蛇の攻撃後に鳥へ変形し、周回ごとに蛇の攻撃も進む。
- 突進は1.2秒予告、0.28秒攻撃。幅8の直線帯を進み、横回避または側面の緑の鱗へ退避する。
- 叩きつけは1.5秒予告、0.24秒攻撃。半径8・高さ32未満の柱が危険。上に登るだけでは避けられず、側面へ逃げる。着地時は砂埃・低い音・距離減衰する振動が出る。
- 鳥は空中のプレイヤーに片翼払いを行う。1.2秒予告後、0.38秒かけて捕捉済みの空間を横切る。赤い範囲から別ルートまたは落下で離脱する。空振り後は3秒、羽根破壊数に関係なくコアを狙える。
- 鳥の通常のコア開放（羽根3枚）は最初の片翼払い後から有効。予告・攻撃中は閉じ、連打で攻撃を飛ばして終了する流れを防ぐ。
- 攻撃開始位置は予告開始時に固定。すべて一度だけ22ダメージ。新攻撃も既存の無敵・予約解除・復帰を使用。
- カメラは予告中の攻撃部位を参照し、地上では自機の見やすさを優先して見上げを制限。チェーン先を滑らかに先読みする。画面外方向表示も攻撃部位を参照。
- F6でシェイクを100%→0%→50%と切り替える。方向性のある減衰振動は描画用ビューだけに加え、照準・選択用の基準位置は変えない。小さい衝撃が大きい衝撃を上書きせず、振幅と時間にも上限を設ける。
- 安全な鱗は停止なし、通常命中は25ms、コアは80ms。コア命中の反動が部位へ遅れて伝わる。停止中も視点と回避予約を受け付ける。
- 変形は往復とも従来のボス時間8秒。パーツ一枚の分離・収束は0.32秒を基本とし、開始をずらして波を作る。格子内の組み替えも短い加減速で実行する。5次補間と曲線経路で移動の継ぎ目を滑らかにする。既存のスロー・ヒットストップ時の時計の扱いは維持。
- 攻撃別の検証は `tests/Run-ChronoSmoke.ps1 -Snake -AttackPattern 0`（横薙ぎ）、`1`（突進）、`2`（叩きつけ）。`-Creature` は片翼払いを経て空中反撃し、蛇へ戻るまでを検証する。

## 長押しチェーン・距離とメリハリ

- AUTOは左クリック長押しで接近・命中・次のチェーンを連続実行。離すと次の予約を破棄する。SHIFT回避後は一度クリックを離すまで再開せず、意図せず飛び戻らない。手動照準は従来通り。
- AUTOの手の伸長速度は160、命中後の復帰は0.025秒。連鎖で速度倍率が最大150%まで上昇し、FOVも連動する。
- 蛇の待機と変形中は、プレイヤーから水平約90離れた周回先へ加減速して移動する。予告後は位置を固定し、攻撃する頭・翼だけが接近する。使用中の羽根ルートを移動で引き離さない。
- 蛇の緑の鱗は攻撃ごとに5個だけ配置し、使うと消費。攻撃終了後・変形時には閉じる。古い常設球アンカーは巨大生物戦から除去した。
- 鳥の羽根は一本のルートに整理。利用済みの羽根と終了した攻撃の羽根は除去し、遠くの安全な羽根は非表示にする。飛来中の危険な羽根は隠さない。捕捉中の対象は移動完了まで保持する。
- 片翼払いの予告・攻撃・回復は実時間で進む。チェーン中のスローで予告だけ延び、最後の羽根を使い切って落下する状況を防ぐ。変形は従来通りボス時間8秒。
- シェイクは衝突時に最大振幅から開始して減衰。叩きつけは距離で振幅と周波数が変化する。微小な滑らかな揺らぎも描画だけに加え、F6の強度設定と連動する。照準計算は揺らさない。
- `-Creature`検証では、長押し中に3回以上連鎖すること、ボスの移動、変形中の残留オブジェクト除去、空中コア命中と回避復帰も確認する。
