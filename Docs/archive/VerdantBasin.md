# Verdant Basin / 本編フィールド

本編は `Resources/Scenes/chrono.json` の1ステージ。ステージセレクトから直接開始する。
旧 `scene.json` / `stage2.json` と装備選択シーンは削除し、共有モデルは保持した。
ビルド時にも、出力先に残った旧2シーンのJSONを削除する。

## 構成

- プレイ領域：280 × 300（旧160 × 170の約3.09倍）。中心は (0, 0, 20)。
- 外周は低い草地の縁で表示。プレイヤー中心は X ±138、Z -128～168 に制限。
- 中央に既存の連続斜面2本と高さ18の高台。塗膜・接地・流体支持面を共通に維持。
- ステージ2と同じ Quaternius の草地、Tree、Rock_1、RockPlatforms_Large、Tower を使用。
- 外景は28の岩山、32本の木、16の岩、奥の城。背景には物理・GPU流体コライダーを追加しない。
- 雑魚敵は配置しない。蛇／鳥に変形する既存ボス1体と戦う。
- 鳥は外周のプレイヤーにも射程内まで接近する。
- 本体質量・回収・3段階ビーム・低HPからの回復は既存ルールを維持。

地形本体は既存モデルを使用し、塗膜は共有1024²アトラスの既存13面。
アトラス枚数やコライダー数を背景オブジェクト数に比例して増やさない。
接触領域の更新は差分塗りのまま。遠景は通常メッシュ描画の負荷のみ増える。

## テストシーン

Development構成の `--test-scene` で従来の Assignment テストシーンを起動できる。
ステージセレクトで F1 を押しても開ける。
流体・蛇・鳥等の診断CLIも維持。通常のステージセレクトには表示しない。

## 検証コマンド

- `tests/Run-ChronoSmoke.ps1 -SlimeField`：外周4方向の接地・移動制限・塗り、ボス1体、雑魚0、背景コライダーなし。全景を `tests/out/verdant-basin.png` に保存。
- `tests/Run-ChronoSmoke.ps1 -SlimePolish`：坂の往復、ジャンプ・着地、流体支持。
- `tests/Run-ChronoSmoke.ps1 -SlimeLow`：HP8からコア3つを破壊する実戦。
- `tests/Run-ChronoTests.ps1`：質量収支と接地等のCPUルール。
