# ゲームHUD デザイン案

街を食べるスライムという題材から出した 4 方向です。背景は実際のゲーム画面 (HUD を消して撮影) です。
`python render.py` で各 HTML を 1280x720 の PNG に書き出します (Edge を使用)。

| 案 | ねらい | 向き / 不向き |
| --- | --- | --- |
| A 標本ラベル (`a_specimen`) | スライムを「研究所の標本」として扱う。体力はフラスコの液量、子分は試験管、変形は索引カード | 調合室とつながる。紙の質感はゲーム中に情報が多いと重くなる |
| B 道路標識 (`b_street`) | 街の案内標識・速度標識・工事テープ・ステッカーで HUD を作る | 舞台の街に溶け込み、一目で読める。色数が多くなりやすい |
| C 足元の輪 (`c_diegetic`) | 枠をほぼ無くし、体力はスライムの足元の輪、章の見出しは入った時だけ表示 | 画面が最も広い。体力が視線の中心にある。初見の分かりやすさは他案より弱い |
| D 緊急中継 (`d_broadcast`) | B級怪獣映画のニュース中継。目標が「速報」の見出し、操作説明はテロップで流れる | 演出として最も個性的。下の帯が大きいので、常時表示は細い帯にする必要がある |

## 採用案

B 道路標識の HUD (体力ゲージ・子分の数・変形のステッカー・操作の1行) に、C の上部中央の章の見出しを合わせた `e_combined` を採用し、`ChronoSystem::DrawSlimeLifeUI` に実装しました。
見出しは段階が変わると約5秒大きく出て、その後は上部の小さな1行 (場所と目標) になります。

変形のアイコンと子分の塊・ステッカーの下地は `Resources/Textures/UI/HUD/` の白い PNG (128x128・透明) です。色はゲーム側で付けるので、差し替えるときは同じ名前の白い画像を置いてください。
