# Slime Assault — 移動の軌跡を解放するボス戦

通常の `chrono.json` は、液体弾の連射から接触塗り・回収・圧力ビームへ変更。

## 操作

| 操作 | 動作 |
| --- | --- |
| WASD | 常時スライド移動。接地移動に応じて体の質量を地面へ預ける |
| 右クリック | 短時間の液状化回避。タイミングが合うとジャスト回避 |
| 右クリック（回収中） | 回収をキャンセルして回避。押し続けても連続回避しない |
| LMB ホールド | 戦闘エリアの自分の軌跡を回収・圧縮 |
| LMB リリース | 回収量に応じたビームを発射 |
| マウス | 照準。発射中はビームの旋回速度を制限 |
| ホイールクリック（中ボタン） | ボスのコアへのロックオンを切り替え。解除すると手動照準に戻る |
| Space / F6 / F4 | ジャンプ / シェイク強度 / 蛇のみの検証 |

## ボスの追跡と羽根連射

変形時は元の各パーツの位置を保存し、その場所で分解する。パーツごとに出発をずらし、個別の曲線軌道で固定した次の形成位置へ飛ぶ。幾何学的な配列全体を移動させず、移動先の鳥・蛇の各部位へ直接組み上がる。往復とも同じ仕組みを使用する。

蛇はプレイヤーの周囲を追跡し、体の向きも徐々に変える。攻撃の予備動作・攻撃・短い隙では位置を固定し、復帰時に追跡を再開する。
鳥はプレイヤーの移動範囲外、遠景の内側を飛行する。飛行時の体を縮めて外周に収め、プレイヤーへ向きを変えながら巡回する。約1.15秒の予備動作で翼を持ち上げて停止し、0.14秒間隔で9本の扇状弾を20波、合計180本発射する。扇の向きが左右へ振れ、速度62の羽根の列には回避できる隙間を残す。羽根は発射時の狙いへ直進し、地形で止まり、ビームで消せる。連射後はコアに隙ができ、2回の連射サイクル後に蛇へ戻る。
ロックオン中はカメラと照準がコアを追従する。ビームは全段階で射程700となり、場外の鳥にも届く。威力差と旋回速度制限、遮蔽物による停止は維持する。右上にホイールクリック案内、対象にLOCKED表示を出す。

`tests/Run-UISmoke.ps1 -Boss`で本編の追跡・場外飛行・予備動作停止・180本の弾幕・変形中のルート固定・ロックオン切替を検証し、`tests/out/boss-volley.png`へ描画を保存する。

## 質量

体内 + 床 + 発射中の質量を管理する。圧縮量は体内質量に対する攻撃権であり、追加HPではない。
最大質量は800（従来の8倍）、移動消費の最低質量は総質量の5%（最大40、最低1）。被弾は体内質量から引かれ、0で敗北する。回収と発射後の復帰は被弾損失を回復しない。
歩行0.65、スライド1.05、回避1.3の質量/距離で消費。停止・空中・壁への押し付けでは蓄積しない。
床・坂・台座・接触した台座側面に軌跡を残す。回収量の正本はCPU上の軌跡で、描画マスクは10Hzで再構築する。
キャンセルした圧縮量は体に残るが、次の攻撃には再度撒く必要がある。発射した量は約0.45秒で体に戻る。

## ビーム

最大質量時のチャージ容量760。被弾後は残存総質量から生存用質量を引いた容量に切り替わる。35%未満がレベル1、35〜75%未満がレベル2、75%以上がレベル3。
噴射時間0.35〜1.2秒、半径0.28〜2.88、全段階共通の射程700。DPSは18 + 135 × チャージ率²、0.05秒刻み。
レベル2で螺旋と圧力リング、レベル3で大きな発射リング、2本の螺旋と5つの移動リング。
共通プレイヤー色から着色した液柱・芯・飛沫と、生成した圧力/吸収/酸の効果音を使用する。
レベル3発射時は0.03秒でモノクロ化、0.08秒まで保持、0.20秒で通常色へ復帰。HUDは後段描画。

回収開始時に体内質量が生存用質量の2倍以下かつ床に現在の容量の75%以上を預け、レベル3を発射すると限界突破。
命中時に1噴射につき一度、3.5秒のダウンとコア露出を与える。通常ビームも閉じた装甲を溶かすとダウン可能。
コア耐久100を3回破壊してクリア。蛇と鳥の既存形態・攻撃予告を利用する。

- `Resources/shaders/SlimeBeamPS.hlsl`: 色付き液柱。
- `tests/GenerateSlimeMeshes.ps1` / `GenerateSlimeAudio.ps1`: 同梱のオリジナル素材の再生成。
- `tests/Run-ChronoTests.ps1`: 質量保存、被弾損失、キャンセル、再利用防止、段階、時間曲線など。
- `tests/Run-SlimeAssetTests.ps1`: エンジンと同じAssimp設定でビーム素材の読込を検証。

- `tests/Run-ChronoSmoke.ps1 -SlimeBattle`: 実入力でボスのコア3回破壊を検証。

左右の緑色障害物はビームで溶解でき、耐久が尽きると通行可能になる。敵の投射物として登録された当たり判定もビームで消去する。ボス本体や攻撃予告は消去しない。通常戦への新しい弾幕パターン追加や全地形破壊は行っていない。

## 操作感の改善

質量増加後も体の寸法・ビーム射程・反動・被弾ダメージは最大質量に対する比率で調整する。坂道は移動距離から許容する高低差を計算し、下降時の接地切れを防ぐ。ジャンプと崖からの落下は維持する。
プレイヤー本体はGPU流体粒子の密度から表面を復元する。解析的なドームの別描画は使わない。PBFの圧力・粘性・衝突を維持し、半楕円体の柔らかい拘束と外力で粒子の分布をドーム状に整える。通常とスライドで拘束領域の体積を維持し、質量は有効粒子数で表す。通常プレイでは速度デバッグ表示を無効化する。
効果音は48 kHz、帯域制限したノイズと滑らかな音量包絡を使う。発射音を減音し、着弾音の再生間隔を0.22秒にして重複を抑える。
坂道往復と残量・描画の確認: tests/Run-ChronoSmoke.ps1 -SlimePolish。


粒子位置のGPU検証: tests/Run-FluidTests.ps1 -Case --slime-only。通常の凸状の頭頂、スライド時の扁平化、質量20%時の粒子数と縮小、有限値・床の非貫通を本番HLSLで確認する。

## 接触輪郭と柔らかい動作

カメラの基準距離は17。塗り跡はGPU流体粒子をフレームフェンス完了後に読み戻し、各面から0.55以内の粒子を32方向の輪郭へ集約して塗る。固定幅ではなく、質量・スライド・実際の変形に追従する。読み戻しの数フレームの遅延はコア相対座標で補正する。各面のマスクは256四方、全体アトラスは1024四方。回収時だけ預けた量の比率で輪郭を縮める。
空中では支持平面を解除し、拘束を弱める。移動を完全転送せず粒子の追従に遅れを残す。ジャンプの縦伸び、着地時の扁平化と復元は体積を保つ制御場と減衰ばねを通じて粒子へ作用する。描画は粒子密度の復元を継続する。
SlimePolish検証は坂道往復に加えてGPU接触輪郭の取得・ジャンプ頂点・着地後の粒子高さを検査する。

## 塗り負荷と進行方向の変形

塗り足しは新しい接触輪郭だけをマスクへ加算し、過去の全軌跡の再描画は回収時に限る。塗膜の再転送はフレームのアップロード領域を使って通常のコマンドリストへ積み、毎回のWaitGPUと転送用リソース生成をなくした（初回作成のみ同期）。小さい台座面で300本の履歴を持つ比較テストは、12更新合計で全再描画1137ms・差分追加3.6ms、マスク一致。ゲーム全体のFPSではなくCPU塗膜処理の測定。
流体制御場は実際の水平速度に追従し、前が広く後ろが細い形へ滑らかに変形する。速度が落ちると通常形状へ戻り、空中では方向変形を弱める。GPUテストで正方向と反転方向の前後幅を検査する。

## 斜面の支持と低HPの立て直し

流体の支持面に接地面の勾配を渡し、水平な底面と坂が競合しないようにした。台座上面は同じ連続支持面で扱い、拡張AABBの前面による押し戻しを除く。120Hzソルバーの各ステップでコア位置を補間する。
攻撃の容量は、回収開始時の総質量（体内・床・発射中）から生存用質量を引いて決定する。生存用は総質量の5%（最大40、最低1）。35%/75%の段階、威力、射程、太さはこの容量に対する割合で計算し、被弾で最強ビームが永久に使えなくなることを防ぐ。撒く速度も容量比で補正する。
4秒無被弾かつ通常移動状態では毎秒32ずつ総質量200まで再生する。床に撒いた分も総量へ含めるため、撒いて回復を繰り返して増殖はできない。死亡後は再生しない。HUDに現在のフルチャージ量と再生状態を表示する。
検証: Run-ChronoSmoke.ps1 -SlimeLow はHP8から実入力でコア3個の破壊を試行する。SlimePolishは斜面に対するGPU粒子の最小高さと重心高さのフレーム間変動も検査する。

コア破壊時は失った質量を全回復する。床・発射中の質量を含めた総量800を上限とし、次のフェーズで立て直せるようにする。低HPの通し検証では、ボスの攻撃後の隙まで回避し続けてから回収・発射する。

## ジャスト回避

右クリックで回避開始後0.12秒以内に羽根または蛇の範囲攻撃が重なると、1回の回避につき1回だけ成功する。無傷・0.4秒のグレー演出と敵速度15%、0.16秒の見た目の収縮に続き、半径約22へ48個の回収可能な塗りを散布する。散布量608はHPから独立したボーナス液。散布・回収・発射でHPを消費せず、回収分をボーナスチャージとして管理する。低HPでも同量を得られる。通常の移動塗りとは分け、回避中・成功演出中の移動塗りによるHP消費も停止する。回避開始位置も短い成功窓の間だけ判定し、早く回避して攻撃から離れた場合の空振り成功を防ぐ。

検証: tests/Run-UISmoke.ps1 -Dodge（羽根と蛇の成功、早過ぎる回避の被弾、グレー・スロー、ボーナス塗りと散布時のHP維持）。

操作変更: Shift入力は本編では使用しない。通常の接地移動は自動スライド（速度27）とし、液状化表示は0.18秒の回避アクション中だけ有効。右クリックの立ち上がりで1回だけ回避し、長押しでの継続・クールダウン後の自動再発動は行わない。

回避後の保護: 通常回避は開始から0.45秒（動作終了後約0.27秒）、ジャスト回避は成功から0.95秒無敵。次の通常回避で残存無敵時間を短縮しない。成功時は画面中心を鮮明に保つ周辺ラジアルブラーと最大約7度のFOV拡大を0.4秒で戻す。蛇の成功窓0.12秒、羽根は0.24秒。羽根のみ成功判定半径4（通常被弾半径2のまま）のかすめ判定を使う。回避クールダウン0.65秒は維持。追撃を当てる実シーンテストで通常・成功後の保護と無敵終了後の被弾を確認。

## ビームカメラ
弱・中は右肩越し（右オフセット6）、強はさらに右14・後方22・上4.2へ移動して液柱を斜めから見せる。Smoothstepで発射時0.22〜0.28秒、復帰時0.36〜0.42秒の遷移を行い、注視方向とチャージ時の引きも平滑化する。照準入力はカメラ演出から独立し、既存の地形へのカメラ衝突判定を維持する。tests/Run-UISmoke.ps1 -BeamCameraで全3段階の実描画と復帰を確認し、tests/out/beam-camera-1.png〜3.pngを保存する。

チャージ中も同じカメラを使用。弱チャージから右肩越しへ移り、35%〜75%の蓄積量に応じて強ビーム構図へ連続的に移行する。発射時にも同じ蓄積比率で構図・引き・FOVを維持し、キャンセル・終了時はイージングで通常視点へ戻す。BeamCamera検証は3段階のチャージ中の構図も検査する。
