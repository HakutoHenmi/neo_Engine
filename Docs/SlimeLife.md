# スライム調合・成長アクション

2026-10-15。通常プレイの実装仕様。草原の地形・背景と地上敵のモデルを引き継ぎ、ゲーム進行を刷新した。

## 遊び方

調合画面で配合と色を選び、出撃する。本体を直接動かし、被弾で自然分裂した子スライムは自動で追従・索敵・攻撃する。小物や弱らせた敵をボタンで包み込み、質量を増やす。分裂・集合を指示する操作はない。

草原には18体の地上敵を有限配置する。全て倒すか取り込むとクリア。被弾と分裂で本体HPが減り、ゼロで失敗。子が生きていても本体の代わりにはならない。接触合体・子の回収・出発地点での自動回復は行わない。

線・囲い・追尾弾・ラン内カード・1000体撃破後のボス出現は、通常プレイの経路では使用しない。旧コードは既存の検証用に残してある。

## 取り込み

本体は接触だけでは取り込まない。一回のボタン押下で一回だけ実行し、長押しは次の対象へ連続実行しない。

正面付近にいる吸収可能な対象を選び、対象方向へ正面を合わせる。正面から左右の丸い腕を伸ばし、くぼんだ厚い手のひら、各手の三本の太い指と親指を作る。大きく開く→対象の側面と奥へ回り込む→指を上から内側へ丸めて包む→閉じた両手を本体へ引き込む、の順で取り込む。対象の距離・左右位置・高さと本体の質量に合わせて調整し、対象の位置も追跡する。成立前に対象が範囲外へ逃げると、取り込みを中止して復元する。

通常敵はHP30%以下に弱らせてから取り込める。大型の装甲敵や石には、より大きな質量が必要。対象は予約して重複取得を防ぎ、質量の更新は変形の復元後に行う。倒した敵も回収可能な塊を残す。

## 分裂と耐久

開始質量100、群れの最大質量400。無敵時間外の本体への被弾で、まず攻撃ダメージを引く。本体が生存し、子の空き枠があれば自然分裂する。取り込み・変形中の被弾でも発生し、進行中の姿勢を復元する。成立済み取り込みの成長分は失わない。

分裂時に渡す質量は配合による上限と本体質量に対する割合の小さい方。初期配合では従来と同じ20または25%。水が多いと大きくちぎれ、のりが多いと本体を残す。最大HPも質量比で渡し、子の現在HPは「子の最大HPまたは本体の残HPの小さい方」を本体から引く。この移譲で本体HPがゼロになっても失敗する。本体HPを最低1残す保護はない。群れ全体の質量・粒子数は保存し、群れ全体の現在HPは配合補正後の攻撃ダメージ分だけ減る。

子は最大三体。上限に達しても被弾ダメージは受け、HPがゼロになるまで減る。本体に最低質量40を残す旧制限は廃止。子は自律戦闘と追従だけを行い、接近しても合体しない。子のHPがゼロならその場で戦闘不能になる。取り込みによる成長は最大HPを増やすが、現在HPを回復しない。

## 点群による変形

ハンマー・剣・飛行機の閉じたメッシュから、内部を満たすターゲット点群を事前計算する。各個体の粒子数Nと目標数を一致させ、GPUで空間順序による一対一対応を作る。対応は元の粒子スロットへ保存し、流体の空間ソート後も維持する。

粒子を目標位置へばねと相対速度の減衰で追従させる。既存の密度補正・粘性・衝突・表面再構成を継続する。形状誤差はGPUで集計し、少量の非同期読み戻しを使って攻撃判定の開始条件にする。

通常時と復元時には粒子を個別の目標点へ固定しない。以前の液体表現と同じ、柔らかい体積境界・密度補正・粘性で形を支える。ジャンプすると下面も自由に丸まり、着地では体積を保って潰れ、揺れて戻る。武器変形・取り込み中にだけ個別の点へ追従させる。

個体の粒子数は被弾分裂で配分し、成長中は保持する。個体ごとの質量と粒子数から目標密度を計算する。別個体の変形開始で実行中の対応付けを上書きしない。所有スロットが変わる被弾分裂では、進行中の形を復元経路へ移してから全体の対応を更新する。

取り込みも同じ追従機構を使う。`Engine/SlimeEngulfShape.h` で通常点群から本体・腕・手のひら・指・親指の所属を固定し、ベジェ曲線の体積を持つ腕と指、厚みのある球殻の手のひらへ目標点を連続変形する。別の手のメッシュを重ねず、本体の実流体粒子だけで両手を作る。粒子数を保ち、分裂・成長等の変更時に割り当てを更新する。変形の立ち上がりは配合ごとの取り込み時間に合わせるため、速い配合でも最初から手が伸び始める。調合室でも同じ変形を使い、目標点と実粒子の両方をカメラ範囲に含める。

## 調合と保存

専用の調合室で、中央の作業台に実際のGPU流体スライムを表示する。左に材料、右に色と手触り、下に試す・保存・出撃のUIを置く。草原の敵や吸収物は表示せず、戦闘状態も進めない。プレビューは開始質量100で、戦闘中の大きさ・HP・子に影響しない。

ゲーム内素材の洗濯のり・水・ホウ砂水を増減すると、プレビューへ即座に反映する。洗濯のりは粘性と揺れの減衰、水は横への広がりと流れやすさ、ホウ砂水は弾力とまとまりやすさに大きく影響する。移動速度・ジャンプ・取り込み速度にも配合差が出る。五回取り込むと、軽さを増す素材「泡」が解放される。色はHSVカラーピッカーで自由に選べ、保存枠は三つ。

色相バーと彩度・明度の面をドラッグすると、選択した色を同じ描画フレームの表面色へ反映する。RGBの16進表記も表示する。ゲームパッドでは選択した色領域を右スティックで調整する。保存形式v2はRGBとHSVを保持し、v1の六色プリセットは同じRGBへ変換して読み込む。黒や白を選んでもHSVの色相を保持する。

プレビューのカメラは、配合・ジャンプ・実際のGPU粒子の範囲から、上下左右のUIの間に全身が収まる距離を計算する。水100%の静止・着地でも下部ボタンや保存パネルに隠れないようにする。

通常移動では実際の速度方向へ少し広がり、方向転換すると古い向きの伸びがほどけて新しい向きへ形が移る。世界座標で水平面の対称な変形を補間し、面積と体積を保つ。細長い本体を旋回方向へ回したり、尾を横へ曲げる補正は使わない。停止すると伸びも自然に解消する。顔の向きは滑らかに追従し、攻撃方向の即時入力とは分離する。極端に薄い配合でも体積を保って最低限の厚みを確保する。描画は従来の0.56単位固定グリッドから、通常時は0.18単位を基準に全個体を包む範囲へ適応させ、薄い表面の角ばりを抑える。

移動・振り向きの主導は内部の液状コアと目が担う。操作されたコアが先行し、外側の柔らかい境界は配合に応じて遅れて追従する。従来の全粒子への共通の水平移動を廃止し、コア付近だけに速度追従力を加え、圧力・粘性・表面張力で周囲へ運動を伝える。反転直後も外側には元の方向の慣性が残る。通常形状の各粒子を個別の点へ固定しない。ジャンプの鉛直移動は維持する。停止中も視線方向へコアと目を先に向け、全体を一度に回転しない。

内部コア自体は描画せず、流体を動かす制御点と目の位置の基準として使う。目を従来の外周まで押し出す投影は通常形状では使わない。地形による遮蔽と後ろ向きの目の非表示を保つ。武器変形・取り込みでは従来の点群への追従と表面に沿う顔の描画を使う。

配合をゲーム体験へ直接反映する。水は速い加速・広い取り込み範囲と角度を持つが、止まりにくく被弾時の損失が大きい。のりは移動と切り返しが重い一方、素早く包み、対象を保持できる範囲が広く、本体の被ダメージと分裂時の損失が小さい。ホウ砂水はジャンプと踏みつけの威力・範囲を伸ばし、50%以上で着地後に一度跳ね返る。泡は低重力と子の移動速度・攻撃頻度・威力を伸ばし、本体は傷つきやすく吹き飛ばされる。通常の吸収条件やサイズ条件は変えない。

純素材の比較値（開始質量100）：水は移動速度28・取り込み距離7.77、のりは速度6・取り込み0.45秒、ホウ砂水はジャンプ初速24・踏みつけ54ダメージ/範囲8、泡は重力14・子の攻撃間隔約0.27秒。同じ8ダメージからの分裂では、水の本体HP約60.3に対しのりは約86.3残る。途中の配合も割合に応じて連続的に変化する。

調合画面には型・得意な行動・弱点と、実際の移動速度・取り込み時間/距離・踏みつけ威力/範囲・被ダメージ倍率・子の攻撃頻度を表示する。草原にも型を表示し、取り込みや踏みつけ、被弾分裂の結果を数値で知らせる。

POKEで揺れ、JUMPで高さと滞空・着地の変形と衝撃範囲を確認できる。AUTOは定期的にジャンプする。MOVEは同じ時間だけ往復し、到達距離と止まり方を比較する。ABSORBは実際の点群変形で見本を包む。HIT:8は本番と同じ被弾処理で本体と子のGPU流体を分け、残るHPと子の大きさを表示した後、試遊をリセットする。試遊は本番のHP・質量・素材解放・保存に影響しない。手動分裂・集合は草原には追加しない。

WATERY / BOUNCY / STICKY / FOAMで性質の異なる配合を比較できる。FOAMは素材の解放後に使用できる。材料の変更時は滴が落ちて混ざる演出と揺れを加える。プレビューと草原で同じ物性・移動・取り込み・被弾分裂のルールを使う。

調合画面のSAVE RECIPEで保存、TRY / RESUMEまたはTabでその配合のまま草原へ戻り、SAVE & DEPLOYで保存して新しい出撃を始める。配合と素材の解放は `%LOCALAPPDATA%/LiquidTime/slime-lab-v1.json` に保存する。出撃・リトライで大きさ、子、現在耐久、変形状態を初期化する。ステージで成長した大きさは持ち越さない。調合室との行き来で粒子を再配置する際も、戦闘側の質量・HP・子・予約済み成長を保持する。

調合中はカーソルを表示して中央固定を解除し、戦闘とプレイ時間の計測を停止する。調合画面でポーズして復帰した場合も、この状態を維持する。

## 検証と素材

Releaseは実行ファイルと同じ場所の `Resources/shaders` を起動時に読む。通常の出力先は `../Generated/Outputs/Release`。シェーダー修正時はこの出力先にも反映し、通常のRelease実行ファイルで確認する。`bld/SlimeLife/bin` は別の検証用出力先。

- `tests/Run-SlimeLifeTests.ps1`: 被弾分裂時の質量・HP・粒子数の保存、低HP分裂での死亡、子の上限時のHP減少と死亡、取り込み条件、ジャンプと着地の変形・配合の物性差・体積保存、閉じたメッシュからの点群生成。GPUでは一対一割り当てとPBFを含む武器追従、通常時の点固定の撤去、空中下面、配合による実際の粘性差を確認する。
- `tests/Run-SlimeLifeSmoke.ps1 -Executable <exe>`: 実ゲームで調合中のカーソル移動・配合ボタン・保存・ポーズ復帰・戦闘時間停止、中央の実粒子プレビュー・GPUへの物性反映・プレビューのジャンプ下面、手動取り込みと長押し、実敵の被弾分裂・子の自動戦闘・三種の変形・本体HPゼロでの終了とリトライを確認する。Developmentビルドで実行し、`tests/out/slime-life-*` にレポートと画像を保存する。変形確認の区間だけ検証側で無敵時間を延長し、終了確認では解除する。
- 同スクリプトの `-LabOnly` は、カラーピッカーから自由な色を選び、選択フレームでの描画色の一致を確認する。追加で水100%とBOUNCYを実際のボタンで切り替え、GPU粒子の横幅・高さの差、静止・空中・着地で全身がUIの間に収まること、細かい表面グリッドが使われることを確認し、画像を保存する。
- 同スクリプトの `-MixtureOnly` は、実際の配合プリセットとMOVE/ABSORB/HIT/JUMPボタンを操作し、水とSTICKYの到達距離・被弾後のHP・分裂時の質量/粒子保存・取り込みの点群変形・BOUNCYのジャンプ高さを比較する。本番の状態を変えず、試遊中もUIの間に収まることを確認する。純素材の加速/減速・滞空・吸収範囲・踏みつけ・子の攻撃性能はルールテストで比較する。
- 同スクリプトの `-TurnOnly` は、水100%で草原へ戻り、90度ずつの方向転換・斜め移動・停止・停止中の180度の振り向きで、コアの先行・速度方向への変形・停止時の形の戻り・実粒子の有限性と本体付近への収まりを確認する。ルールテストでは30/60/120Hzでの直角旋回・反転・斜め移動・停止・コアと外側の追従差を確認する。GPUテストでは実際の境界補正に加えて、水平の共通移動がないことと、反転するコア付近の粒子に対して外側が元の速度を残すことを確認する。
- `tests/Run-FluidTests.ps1 -Case '--face-only'`: コアと目の位置関係が外側の位置から独立すること、目の形・間隔・質量スケールを保つこと、通常・薄い形状・コア追従の描画で両目が見えることを確認する。描画用のコア座標はグラフィックスだけに渡し、流体の密度再構成の定数とルート署名の予算は維持する。
- `tests/Run-FluidTests.ps1 -Case '--near-volume-only'`: 0.18単位のグリッドで薄い流体の連続した表面、密度の保存、描画深度、遮蔽、遠方表示、履歴の除去を確認する。
- `tests/GenerateSlimeLifeAssets.py`: オリジナルの武器用閉メッシュと、分裂・取り込み・合体の音を再生成する。

配合による動作差、分裂の手触り、ASMRの音量、変形の速度は、実機で継続調整する対象。計画時の詳細は [全体プラン](SlimeRebootPlan.md) と [点群変形プラン](SlimePointCloudMorphPlan.md) を参照。

全GPUテストを指定なしで実行した場合、旧コアの `player crown is pushed sideways or collapses` 判定で失敗する。この判定は変更前のHEADのシェーダーでも同じく失敗することを確認した。今回の通常液体・配合・点群変形の検証は `--morph-only` で独立して実行する。

`--volume-only` には、変更していない密度再構成シェーダーの0.56単位グリッドで、薄い流体が `a bulk phase disappeared` 判定に失敗する既存の問題もある。今回追加した0.18単位の検証は通過する。
