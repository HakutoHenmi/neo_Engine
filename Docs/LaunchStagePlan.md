# 第二ステージ「スライム射出チャレンジ」計画

> **2026-11-19: この案は [戦闘フェーズ案](BattlePhasePlan.md) に置き換え。** 射出の試作コードは削除済み。

## 軸 (変えないこと)

- **吸収して大きくなる爽快感が主役。** 部屋・坂の町の吸収ステージはそのまま活かす。
- 足りないのは「集めたものを使う理由」。吸収のあとに、集めた結果を**使い切る**ステージを足す。

## 全体の流れ

```
吸収ステージ (2〜3 分) → [スナップショット保存] → 射出チャレンジ (30〜60 秒) → リザルト
                                                    ↑         │
                                                    └─ 再挑戦 ─┘ (吸収はやり直さない)
```

- 今は `FinishDevour()` → `Finish()` → 結果画面 (`ChronoSystem::Update` の `finished_` 分岐)。
  この間に射出フェーズを挟む。
- リザルトは「吸収の大きさランク」+「射出の記録」の二本立てにする。

## 射出チャレンジの中身

### 遊び
1. 吸収を終えたスライムを発射台 (またはその場) に構える。
2. 角度と力を決めて発射 (スリングショット風。引いて離す)。
3. 建物・家具を**突き破りながら**飛んでいく。止まった地点・壊した量が記録。
4. 空中で少しだけ操作できる (左右にずらす程度。やりすぎると吸収の価値が薄れる)。

### 大きさのトレードオフ
| | 大きい | 小さい |
|---|---|---|
| 破壊力 (貫ける物の大きさ・止まりにくさ) | 高い | 低い |
| 重さ (初速・飛距離・落ちる速さ) | 重い・すぐ落ちる | 軽い・よく飛ぶ |

- 「大きいほど常に有利」にしないのが要。ただし吸収の努力が報われないのはダメなので、
  **最高記録は大きい側で出る**ように寄せ、小さくても「遠くまで飛んだ」で別の見せ場がある程度の調整にする。
- 数式の案: `初速 = 基準 / (1 + k·質量^a)`、`貫通力 = 質量^b`。`a < b` にして大きい方がトータルで得。
  係数は `Resources/Data` の JSON に出してエディタで調整できるようにする。
- 発展案 (後回し): 吸収した物の種類で性質が変わる (重い物を多く食べると重く硬い、軽い物で浮く等)。
  `devourEaten_` に何を食べたかがもう残っているので拾える。

### 記録・ランク
- 主: 飛距離 (ゴールラインまでの到達率)。副: 壊した数・壊した物の合計の大きさ。
- 射出の最高記録はステージごとに `slime-lab-v1.json` に保存 (`devourBests_` と同じ扱い)。

## 時間の目安
- 吸収: **2〜3 分**。今の設定は部屋 180 秒・坂の町 300 秒なので、**坂の町を 150〜180 秒に縮める**か、
  射出を足した合計で長すぎないかを試遊で確かめる。
- 射出: **1 回 30〜60 秒**。1 発 10〜15 秒 × 数発、または 1 発で長く飛ぶ形のどちらか (下の「決めること」)。

## 再挑戦 (スナップショット)
- 吸収終了時に保存する物:
  - 体の質量 (`life_.bodies[0].mass`)・見た目に必要な値
  - 食べた物の一覧 (`devourEaten_`)・ランク・吸収の記録
- 射出の再挑戦はこのスナップショットから始める。**吸収 5 分のやり直しはしない。**
- リザルトの選択肢: 「射出だけやり直す」/「吸収からやり直す」/「次のステージ」/「タイトル」。
- メモリ上に持つだけで十分 (ゲームを閉じたら消えてよい)。ファイル保存は不要。

## 実装の段取り

1. **フェーズ追加の骨組み**
   - `ChronoSystem` に `Absorb → Launch → Result` の段階を持たせる (今の `finished_` を分ける)。
   - `FinishDevour()` で記録とスナップショットを取り、すぐ結果画面ではなく射出フェーズへ。
   - 射出の処理は新しいファイル `Game/Systems/DevourLaunch.cpp` + ルールは `Game/Chrono/DevourLaunchRules.h`
     (既存の `DevourGrowth.cpp` などと同じ分け方)。
2. **射出コース**
   - 最初は吸収したマップをそのまま使う (残っている建物・家具を的にする)。食べ尽くした所は空くので、
     射出用に壊れる物を追加で並べる、または専用の直線コースを作るかを試作で判断。
3. **発射と飛行**
   - 狙い (角度・力) の UI とカメラ、放物線の飛行、空中の小さな操作。
   - 当たり判定: 貫通力 ≥ 物の大きさなら壊して減速、未満なら止まる/跳ね返る。
4. **壊れる演出**
   - 突き破る瞬間のヒットストップ・破片・揺れ。既存の `hitStop`・ランブル (`GameRumble.h`) を流用。
5. **リザルトと再挑戦**
   - 結果画面に射出の記録を追加。「射出だけやり直す」ボタン。最高記録の保存。
   - プレイログ (`DevourPlayLog.cpp`) に射出の記録 (飛距離・壊した数・挑戦回数) を足す。
6. **調整**
   - 大きさの係数・コースの長さ・吸収時間を試遊で詰める。テスト (`tests/`) にトレードオフ式の単体テストを追加。

まず 1〜3 を最小で作り、「大きい体で建物を突き破るのが気持ちいいか」を先に確かめる。
気持ちよくなければ 4 以降に進まず方針を見直す。

## 実装状況 (1〜3 の試作)

- 吸収の時間切れ → **射出 (狙い → 飛行 → 記録)** → 結果画面。結果画面の **L / Bボタン** で射出だけやり直せる。
- コード: `Game/Systems/DevourLaunch.cpp`、規則 `Game/Chrono/DevourLaunchRules.h`、調整値 `devour_stages.json` の `launch`。
- 操作: マウス / 右スティックで向き、W・S / 左スティック上下で角度、左クリック / RT (右クリック / LT も可) 長押しで力が往復し、離して発射。
- 自動テスト (`--slime-life-smoke`) と計測 (`--load-profile-auto`) では射出を挟まない (従来どおり結果画面へ)。

### 確認用の起動 (Release でも使える)
```
DirectXGameApp.exe --devour-launch --devour-stage=1                   # 坂の町、10 m で射出から始める
DirectXGameApp.exe --devour-launch --devour-stage=0 --devour-launch-cm=30
DirectXGameApp.exe --devour-launch --devour-launch-at=x,z,向き(度)     # 飛ばす位置と向き
DirectXGameApp.exe --devour-launch --devour-launch-auto               # 1.5 秒後に自動で発射し、tests/out/devour-launch.txt に記録
```
- 自動発射での目安 (坂の町、角度 32°): 6 m → 34 m / 36 個、10 m → 41 m / 28 個、22 m → 27 m / 110 個。

## 決めること (未決)
- 射出は **1 発勝負** か **数発 (例: 3 発の合計)** か。
- 射出コースは **吸収したマップの続き** か **専用コース** か。
- 部屋・坂の町の **両方** に入れるか、まず片方 (坂の町が建物が多く向いていそう) だけか。
- 射出を失敗 (すぐ止まる) したときの扱い: 記録なしでもクリア扱いか、吸収ランクだけで判定か。
