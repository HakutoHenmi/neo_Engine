# 吸収 → 戦闘フェーズ 計画 (作り直し)

[射出チャレンジ案](LaunchStagePlan.md) に替わる案。「集めた物を使う理由」を、射出ではなく**戦闘**で作る。

## 軸
- **吸収して大きくなる爽快感は残す。** ただし吸収は約 2 分に縮め、「戦闘の準備」の意味を持たせる。
- 戦闘では**何を・どれだけ吸収したか**がそのまま戦い方になる (積み木は投げる、ミニカーは轢く…)。
- 成長の大きさは HP・使える変形の数など、**戦闘の地力**になる。

## 全体の流れ
```
吸収 (約 2 分) → 切り替えの演出 (数秒) → 戦闘 (2 分耐える) → リザルト
                     │                      ↑         │
                     └ 吸収の結果を保存 ────┘ 再挑戦 ─┘  (戦闘だけやり直せる)
```
- 今の制限時間は部屋 180 秒・坂の町 300 秒。**どちらも 120 秒前後に縮める。**
  坂の町の成長の速さ (`growth: 1.6`) は 5 分前提で決めているので、`scripts/terrain/simulate_growth.py` で見直す。
- 吸収の結果 (大きさ・吸収した物) を保存して戦闘に渡し、戦闘だけやり直せるようにする。

## 戦闘ステージ
| ステージ | 残す物 | 消える物 |
|---|---|---|
| 部屋 (じゅうたんのまわりの広い場所で戦う) | **家具だけ** (机・こたつ・ベッド・本棚など、吸収できない物)・壁・床の段差 | 小物はすべて (吸収した物も、吸収しきれなかった物も片付ける) |
| 坂の町 | **家など建物はすべて残す** (吸収で飲んだ建物も戻す)。地形・電柱・木など大物 | 吸収した小物 |

- 同じマップを使うので、新しく作るのは敵・攻撃・HUD が中心。
- 建物を戻すのは、吸収で隠した部位 (`devourBuildingParts_`) を表示し直す。吸収では部位を消している所もあるので、
  戦闘で戻せるよう隠すだけにする。当たり判定 (通れなくなる) も戻す。
- **戦闘の大きさの基準 (2026-11-19)**: 敵・弾・ドロップ・速さ・戦う円の広さは、**戦闘を始めたときのスライムの体の半径** (`battle_.unit` = `BattleUnitAt(startMass)`) に比例する。
  大きく育っても敵や弾が豆粒にならず、画面での見え方は同じ。大きく育った強さは HP・使える物の数・ランク (スロット数)・威力 (`BattlePower`) で出す。

## 吸収した物 → 戦闘の使い道
図鑑の項目 (`collection.json`, 128 種) に**戦闘の分類**を足して、データで決める。吸収した数がそのまま弾数・回数になる。

| 分類 | 例 (部屋 / 街) | 戦闘での使い方 |
|---|---|---|
| 投げる | 積み木・ビー玉・みかん・おもちゃのボール・将棋の駒 / 空き缶・サッカーボール・植木鉢 | 体から撃ち出して当てる。大きい物ほど強く遅い |
| 轢く | ミニカー / 三輪車・自転車・軽自動車・タイヤ | 乗り物の形で突進して轢く (今のタイヤの変形の動きを使う) |
| 叩く | 鉛筆・リモコン・ボウリングのピン / 電柱・物干し | ハンマー・剣の形で近くをなぎ払う (今の変形を使う) |
| 守る | トランプ・マンガ・ティッシュ / 段ボール・ごみ箱 | 盾や鎧として受けるダメージを減らす (使うと減る) |
| 特別 | 信号機などギミック系 | 今の信号機の変形 (敵を止める) |
| 回復 | お菓子・みかん (投げると兼用) | 食べて HP を戻す |

- 分類ごとの「在庫」を戦闘の HUD に出し、ボタンで切り替えて使う (今の変形の切り替え 1〜4 キー / 十字キーと同じ操作)。
- 吸収した物の記録 (`devourEaten_`) にはもう図鑑の id が入っているので、分類を引くだけで在庫を作れる。

## 成長 → 戦闘の地力
| 成長の結果 | 影響 |
|---|---|
| 大きさ (cm) | 最大 HP・攻撃の威力・投げる物の飛び方 |
| ランク (D〜S) | 使える分類の数 (例: D=1, C=2, B=3, A/S=全部)、S は特別な技 |
| 吸収した数 | 弾数・回数 (上の表) |

- 体積は戦闘中も変わる (物を使うと縮む)。最大 HP・威力は**今の大きさ**から毎回決める。
- 「小さくても戦える、大きいと楽になる」くらいにする。D ランクで詰むのは避ける (飴玉はいつでも投げられる)。
- 体力・ダメージの仕組みは今のスライムの戦闘 (`body.health` / `LifeHit` / `LifeImpact`) がそのまま使える。

## 敵 (ステージに合った見た目)
今の群れの敵 (`SwarmEnemy`) と街の敵の役割 (`CityEnemy`: 近接・遠距離・盾・突進・大砲・ボス) の**動きを使い回し、見た目だけ替える**。

| 役割 | 部屋 | 坂の町 |
|---|---|---|
| 群れ (弱い・多い) | ほこりのおばけ | カラス |
| 近接 | ぜんまいのおもちゃ兵隊 | 野良犬 |
| 遠距離 | 輪ゴム鉄砲のロボ | 雨雲のおばけ (雨粒を飛ばす) |
| 盾 | ブリキのロボ (正面は硬い) | ゴミ袋のおばけ |
| ボス | 大きなぬいぐるみ / 掃除機 | ゴミ収集車 / 大ガラス |

- 上の表は見た目の候補。**当面は仮置きの見た目 (箱や既存の敵) で進め、動きと遊びを先に固める。**

## 勝ち負けとリザルト
- **クリア: ボスを倒す (時間では勝ちにならない)。負け: HP が 0。** (2026-11-19 に変更)
- 敵は時間とともに増え・強くなり、**1 分 30 秒でボスを出して山場を作る**。ボスを倒すまで戦闘は続く。
- リザルトは「吸収の大きさのランク」+「戦闘の評価 (倒した数・残り HP・時間)」。
- 戦闘で負けても、吸収からではなく**戦闘だけやり直せる**。

## 実装の段取り
1. **骨組み**: 吸収 → 戦闘 → 結果の段階、戦闘だけやり直し、`--devour-battle` で戦闘から直接始める確認用の起動 (Release でも使える)。
2. **在庫**: `collection.json` に分類を足し、吸収した物から分類ごとの数を作る。HUD に出す。
3. **最小の戦闘 (部屋)**: 2 分のタイマー、仮の敵 1 種類 (近接)、「投げる」攻撃、HP。成長で HP が変わる。
4. **成長の影響**: ランクで使える分類の数、大きさで HP と威力。
5. **攻撃を増やす**: 轢く・叩く・守る・回復。
6. **坂の町**: 建物を戻す (見た目と当たり)、街の敵の見た目。
7. **敵を増やす**: 役割ごとの敵とボス、ステージごとの見た目。
8. **調整**: 吸収 2 分での成長の速さ、戦闘の長さと難しさ、リザルト。

まず 1〜3 で「吸収した積み木を投げて敵を倒すのが気持ちいいか」を確かめる。

## 実装状況 (仮の動き, 2026-11-19)
- 吸収 (**120 秒**に変更) → 戦闘 (120 秒) → 結果画面。結果画面の **L / Bボタン** で戦闘だけやり直せる。
- コード: `Game/Systems/DevourBattle.cpp`、規則 `Game/Chrono/DevourBattleRules.h`、物の分類 `collection.json` の `battle`。
- **スロットと袋** (2026-11-19): 吸収した物は種類ごとに「袋」に入る。**物のスロット** (ランク D=1・C=2・B=3・A=3・S=4、デモは 4) に袋から引いた物が入り (1 つに最大 3 個)、
  使い切ると **0.5 秒のルーレット**のあと袋から引き直す。**引く確率は吸収した数の 0.7 乗に比例** (`BattleBagPower`)。**飴玉は固定のスロット**。敵のドロップは袋に戻る。
  HUD の下の段に、スロットごとの図鑑の絵・名前・能力・残り、袋の残りの数。
- **物ごとの能力**: `collection.json` の `action` (省略は `battle` の分類の動き)。投げる以外は変形する (変形中は無敵)。
  | 能力 | 物 | 体の形 | 動き |
  |---|---|---|---|
  | 回る翼 | 竹とんぼ | ヘリコプター | 0.2 秒ごとにまわりを切る |
  | 水鉄砲 | 水鉄砲 | 水鉄砲 | 前へ水の粒を撃ち続け、押し流す |
  | 転がる | ボウリングの玉 | ボール | 前へ転がり、同じ敵に何度も当たる |
  | こま | こま | こま | 回ってまわりを弾き飛ばす (少し遅く動ける) |
  | 剣 | おもちゃの剣 | 剣 (新しい形) | 前を左右になぎ払う |
  | 飛ぶ | おもちゃの飛行機 | 紙飛行機 | 速く前へ突っ込む |
  | ばね | ばねのおもちゃ | ばね (新しい形) | 縮んで跳ね、着地でまわりを押しつぶす |
  | 吸い込む | ハンディ掃除機 | 掃除機 (新しい形) | 前の敵を吸い寄せて削り、落ちた物も吸い込む |
  | ラジコン | ラジコンカー | 車 | ミニカーより長く速く走り回る |
  今までの 5 つ (投げる・轢く・叩く・守る・回復) も同じ能力の表で動く。
- **将棋の駒の技** (2026-11-19、「投げるが多い」への対応の 1 回目): 駒の形 (`BattleShogiShape`) になり、駒の動きで当てる。
  | 駒 | 技 |
  |---|---|
  | 歩 | 前へ鋭く突く (近くて強い) |
  | 香車 | まっすぐ突進して突き抜ける |
  | 桂馬 | 斜め前 (近い敵の側) へ跳び、着地でまわりを押しつぶす |
  | 銀 | 前と斜め 4 方向を同時に突く |
  | 金 | 後ろの斜め以外の 6 方向を同時に突く |
  | 角 | 斜め 4 方向へステージの端まで届くビーム |
  | 飛車 | 前後左右の十字へステージの端まで届くビーム |
  | 王 | まわり全部を吹き飛ばし、3 秒間無敵 |
  突きとビームは、当たる線に沿って駒の色の光の粒を並べて見せる (仮)。
- **袋の引き方の修正**: 引く重みを吸収した数の 0.7 乗 → **0.5 乗**。小さい物は `collection.json` の `bundle` 個をまとめて 1 回分の「束」にする
  (ビー玉・十円玉 5 個、積み木・アメ 3 個)。引く重みも束の数で数えるので、大量に飲んだ小物ばかり出ることが減る。
- **置く・まく物の技** (2026-11-19、「投げるが多い」への対応の 2 回目): 置いた物は `BattlePlaced` として残り、`TickBattlePlaced` で動く。体は液体のまま (ドミノだけ変形)。
  | 物 | 技 |
  |---|---|
  | ビー玉 | 前の扇の範囲へ 9 個まく。転がって止まり、踏んだ敵は「すべった！」で 1.8 秒止まる (ボスは転ばない) |
  | 積み木 | 前に横長の積み木の塔を建てる。敵は通れず、6 秒後に前へ崩れて当たる |
  | ドミノ | ドミノの形で前へ倒れ込み、前に一列 (9 枚) 並べたドミノが順に倒れて、倒れた所の敵に当たる |
  | 絵の具 | 足元の床をまるく塗る (8 秒)。上の敵は遅く (0.4 倍)、自分は速い (1.4 倍)。色は毎回変わる |
  | ぬいぐるみ | 少し前に置くと、敵 (ボス以外) はそちらへ向かう。5 秒後に弾けてまわりを吹き飛ばす |
  置いた物の見た目は、その物のモデルを好きな大きさで描く (`DrawBattleProp`。大きさはモデルの高さと幅の大きい方から決める)。
- **飛び道具の技** (2026-11-19、「投げるが多い」への対応の 3 回目): 投げた物 (`BattleShot`) の `mode` で飛び方を変える。体は液体のまま。
  | 物 | 技 |
  |---|---|
  | 十円玉 | 指ではじくと、当たった敵から次に近い敵へ跳ね移る (最大 5 体) |
  | だるま落としの輪 | 床を滑る円盤。ステージの縁で跳ね返り、何度も往復して当たる (最大 10 回) |
  | ゴムボール | 床と敵で何度も跳ねる (最大 7 回) |
  | 紙飛行機 | 一番近い敵へ向きを曲げながら追いかける |
  | トランプ | 5 枚を扇形に投げる |
  | 鉛筆 | 槍のようにまっすぐ飛び、敵を突き抜ける |
  後ろのカメラから細く見える物 (十円玉・輪・紙飛行機・鉛筆) は、飛んだ跡に色の粒を少しの間残す。十円玉とトランプは起こして面を見せる。
  (トランプは今まで「守る」だったが扇投げに、鉛筆は「叩く」だったが突き抜けるに変えた)
- **止める・弱らせる物と、自分を強くする物** (2026-11-19、「投げるが多い」への対応の 4 回目):
  | 物 | 技 |
  |---|---|
  | リモコン | 「一時停止」。敵が全部 2.2 秒止まる (ボスは 0.8 秒) |
  | まんが | 前に落とすと、まわりの敵 (ボス以外) が座り込んで 3 秒読みふける |
  | かご | 前の近い敵 1 体 (ボス以外) にかぶせて 6 秒閉じ込める |
  | ノート | 紙を飛ばして、当たった敵に貼り付けて 2.5 秒止める |
  | 消しゴム | 消しゴムの形で前をこする。こすられた敵は 6 秒弱り、受けるダメージが 1.5 倍 |
  | 湯のみ | 前へ熱いお茶をまく。かかった敵は 4 秒やけどで削られ続ける |
  | だるま | だるまの形で 4 秒起き上がりこぼし。無敵で、殴ってきた敵にはね返す |
  | 招き猫 | まわりの敵を前の 1 か所へ招き寄せる。8 秒間、倒した敵が物を落とす確率が 2 倍 (上限は同じ) |
  | 急須 | 6 秒間、少しずつ回復し続ける |
  | ティッシュ | 6 秒間ふわふわの雲に包まれ、攻撃をかわす確率が上がる |
  | 靴下 | 足元ににおいの雲を 7 秒置く。敵は雲の中に入れない |
  敵の状態は色で見せる (弱り: 薄い色・やけど: 橙の点滅・止まっている: 灰色)。自分の効き目は HUD の HP の下に残りの秒を出す。
  これで部屋の物で「ただ投げるだけ」の物は無くなった (十円玉などの飛び道具も、それぞれ飛び方が違う)。
- **部屋に 9 つのおもちゃを足した** (上の表の物)。モデルは `scripts/lowpoly/build_lowpoly.py`、図鑑の絵も作った。置き場所は `RoomStage.cpp` の `BuildRoomSets` の最後
  (こま=和室・ばね=机の下・竹とんぼ=おもちゃ箱・ラジコンと水鉄砲=じゅうたん・飛行機=ベッドの上・剣=おもちゃ箱の前・掃除機=本棚の横・ボウリングの玉=部屋の真ん中)。
- 攻撃 (仮): 投げる=その物のモデルを撃つ / 轢く=**車の形**で前へ突進 / 叩く=**ハンマーの形**で振りかぶって振り下ろす / 守る=**盾の形**で 5 秒ダメージ 3 割 / 回復=**ハートの形**で最大 HP の 35% / 飴玉=無限・弱い。
  投げると飴玉は液体のまま。形は `DevourGimmickRules.h` の `BattleCarShape` など (部屋のギミックと同じ粒子の形の仕組み)。
- 移動の速さと加速は普段の移動と同じ。液体の体の動き (`LifeTickMotion`) も普段どおり進める (進めないと体が三日月の形になる)。
- 使うと在庫が減り、増えた量だけ体が縮み、最大 HP と今の HP が同じ割合で減る。下限 (準備フェーズ開始時の大きさ) では飴玉だけ。
  1 回で縮む量には上限がある (吸収で増えた量の 8%、`BattleShrinkCap`)。大きい物を 1 つ使っただけで一気に縮まないようにする。
  デモ (`--devour-battle`) では、どの物も縮む量を同じにしている (全部使うとちょうど下限)。
- 敵 (仮): 赤い球が時間とともに増え、最後の 30 秒に紫の大きい球 (ボス)。ボスを倒したらクリア、HP 0 で負け。画面の上はボスまでの残り時間 (出たあとは「ボスを倒せ！」)。
- **小さくなったときの特殊能力**: 大きいと高火力・高耐久、小さいと高速・高機動。体積を減らすことを戦術のひとつにする。
  「小ささ」は戦闘を始めたときの大きさで 0、下限で 1。小さいほど 移動が速い (下限で 1.9 倍)・敵の攻撃をかわす (下限で 55%)・
  飴玉の連射が速い (待ち 0.22 秒 → 0.07 秒)・飴玉が増える (小ささ 0.4 で 2 発、0.75 で 3 発の扇形)・飴玉が強い (下限で 1.6 倍)。
  HUD の HP の下に小ささのゲージと今の効き目。数値は `DevourBattleRules.h` の `BattleSmall*` / `BattleCandy*`。飴玉の基本の威力も 4 → 6 に上げた。
- **敵のドロップの再吸収**: 敵を倒すと、ステージの物が **12% で 1 個** 飛び散る (ボスは倒した時点で勝ちなので落とさない)。
  **落とす数の上限は「それまでに使った回数の 2 割」** (`BattleDropRefill`、5 回使って 1 個戻るくらい)。減ったゲージがドロップで大きく戻らないようにする。
  近づくと吸い寄せられて吸い込まれ、その種類の在庫が 1 つ増え、体積も戻る (1 回使って縮む上限の 60%。戻るのは戦闘を始めたときの大きさまで、HP も同じ割合で増える)。
  **体より大きい物でも吸収できる。** 落とす物は、その戦闘で使える種類から選ぶ。18 秒たつと消える (最後の 3 秒は点滅)。HUD に「拾った数」。
- **変形している間 (車・ハンマー・盾・ハート) は無敵。** 液体のとき (投げる・飴玉・移動) だけダメージを受ける。
- 戦闘は**専用の広いステージ**で行う。戦闘が始まると、マップの外 (+x の側) に作った平らな床へ飛ばされる。
  戦う円の半径はクリアの大きさの体の半径の 45 倍 (部屋 約 405・坂の町 約 810)。体も敵も円から出ない。縁は黄色の帯と白い柱 (仮)。
  床の色は `devour_stages.json` の `battleColor` (部屋は水色のマット、坂の町は灰色の広場)。この上ではカメラの部屋・坂の町の決まりを使わない。
- 元のマップの片付け (部屋の小物とギミック、坂の町の建物を戻す) は残してあるが、専用のステージで戦うので戦闘中は見えない。
- 結果画面は吸収のときの大きさで出し、戦闘の記録 (勝敗・倒した数・残り HP・最後の大きさ) を右下に重ねる。

## 次の計画: スロットと「物ごとの能力」

### ねらい
- 今は「投げる・轢く・叩く・守る・回復」の 5 つの分類ごとに在庫を持ち、同じ分類なら何を吸収しても同じ動きになる。
- これを **「スロットに入った物そのものを使う」** 形に変え、**物ごとに違う能力 (変形・技)** を持たせる。
  「何を吸収したか」が戦い方に直結し、毎回の戦闘が少しずつ変わるようにする。

### スロットの仕組み
```
[スロット1: ミニカー ×2] [スロット2: ビー玉 ×3] [スロット3: えんぴつ ×1]  …  [飴玉 ∞ (固定)]
          │ 使い切った
          ▼
   準備フェーズで吸収した物の山 (袋) から、ランダムで次の物を引いて入れる
   (たくさん吸収した物ほど出やすい)
```
- **物のスロット** をいくつか (案: 3 つ) と、**飴玉の固定スロット** を 1 つ持つ。飴玉は今までどおり無限・体積は減らない・下限でも使える。
- 戦闘の始めに、袋から引いて物のスロットを埋める。スロットの物を **使い切ったら、すぐ袋から次の物を引いて入れる** (引くときにルーレットの演出を 0.5 秒ほど)。
- **引く確率は、準備フェーズでその物を吸収した数に比例する。** 例: 積み木 30・ビー玉 10・ミニカー 2 なら、積み木 71%・ビー玉 24%・ミニカー 5%。
  - 数が少ない物が全く出ないと寂しいので、数の 0.7 乗にして少しならす案も用意する (`weight = count^k`。k はデータで調整)。
- 1 つのスロットに入る数: その物の残りの数か、上限 (案: 3) の少ない方。引いた分は袋から減る。
- 袋が空になったら、そのスロットは空 (灰色) のまま。全部空なら飴玉だけ (今の「使い切ったら飴玉だけ」と同じ)。
- **敵のドロップ** は袋に戻る (空いたスロットがあれば、すぐそこに入る)。
- **体積** は今までどおり、物を 1 回使うごとにその物で増えた量だけ縮む (1 回の上限あり)。下限では飴玉だけ。
- **ランク** の効き目は「使える分類の数」から **「物のスロットの数」** に替える (案: D=1・C=2・B=3・A=3・S=4)。

- 縮む下限は、**そのステージの準備フェーズ (吸収) を始めたときの大きさ** (部屋 5 cm・坂の町 1 m。`devour_stages.json` の start)。
  **下限に達したら、飴玉を投げつけることしかできない** (他の物・変形は使えない)。
  飴玉は吸収していなくても使え、弾数は無限・体積は減らない・威力は弱い (しのぐための最後の手段)。
- **ボスを倒したら、その場で勝ち。**
- 最後の山場は**ボスを出す**。
- 物の種類を増やすのは**部屋を先に仕上げる** (坂の町はそのあと)。
- 準備フェーズは **2 分**。成長の速さは全体的に上げる (部屋 `growth` 1.6・坂の町 3.6 → 下げて部屋 1.0・坂の町 3.0)。
