# スライムプレイヤー試験場

Development / Debug の **Scenes → Demos → Slime Player Demo** から開きます。起動引数は `--slime-player-demo`、編集用シーンは `Resources/Scenes/slime_player_demo.json` です。

本編の ChronoSystem と GPU 流体を使う専用フィールドです。街の進行・敵・調合室・勝敗を外し、質量600、タイヤ・消火栓・信号機を解放した状態から開始します。本編の調合レシピのセーブデータは読み書きしません。床の格子と黄色の距離目盛りで、移動・ジャンプ・変形後の大きさと動きを見比べられます。

| 操作 | キー |
| --- | --- |
| 移動 / 視点 / ジャンプ | WASD / マウス / Space |
| 変形 | 1 タイヤ、2 消火栓、3 信号機 (キーボードは押した瞬間にその形へ変形。十字キーは選ぶだけで、攻撃ボタンで変形) |
| 変形 / 変形後の攻撃 | 左クリックで変形。タイヤは左長押しでその場で回転を溜め、離すと溜めた分だけ突進 (溜めきると敵やバリケードをひと突き)。消火栓は左長押しで放水。信号機は押すたびに 赤 (足止め) → 青 (止めた敵を並べて横断歩道) → 黄 (マーカー) の順に出し、色ごとに約2秒、黄の後は8秒の点検で使えない |
| 通常のスライムに戻る | R |
| 吸収 / 消火栓の水の防御 | 右クリック |
| 被弾と分裂を試す | H |
| 本体の質量を100ずつ変更 | - / = (100〜1600) |
| フィールド・体・吸収物を初期化 | F5 |
| ゲーム内ポーズ | Esc |

ゲームパッドでは本編と同じ操作 (左スティック移動、右スティック視点、Aジャンプ、十字キーで形を選択、RTで変形・攻撃、Bで戻る、Xで吸収・水の防御) を使えます。

## 停止時のカメラ

Gameビューはゲームの追従カメラ、Sceneビューは自由に動かせる編集用カメラです。停止中は、ゲームの更新を進めずに復元後のPlayerをGameカメラで映します。InspectorでPlayerの位置を変更した場合も表示を追従させます。Sceneカメラの位置はこの処理では変えません。

最初の自動再生にも停止時の復元点を用意し、再生前の編集状態は各システムのResetより前に保存します。プロシージャルな街・試験場のメッシュとテクスチャはメモリ内のPlayスナップショットにハンドルを保持し、停止時に復元します。ファイルへのシーン保存にはGPUハンドルを含めません。

## 回帰確認

- `tests/Run-SlimePlayerDemoSmoke.ps1`: 停止時のカメラ、メッシュ復元、移動・ジャンプ、タイヤの溜め突進と消火栓の放水、被弾分裂、リセット。
- `tests/Run-SlimeLifeSmoke.ps1 -SignalOnly`: 大交差点で信号機を 1 周使い、赤の足止め・青の整列と横断歩道のダメージ・黄のマーカー (動くと大爆発)・点検中に出せないことを確かめる。
- `tests/Run-SlimeLifeSmoke.ps1 -AlleyOnly`: 本編の一つ目の区画 (路地裏) を、タイヤの溜め突進だけで敵を倒しバリケードを壊して抜けられるか。
- `tests/Run-SlimePlayerDemoSmoke.ps1 -CameraOnly`: 街ステージでの最初の停止、再生・停止の繰り返し、プレイヤーの編集位置とプロシージャルメッシュの復元。

画像と結果は `tests/out/slime-demo-*` と `tests/out/stopped-camera-smoke.txt` に出力します。
